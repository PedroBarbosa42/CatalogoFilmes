# 🎬 Catálogo de Filmes — Tom Hanks

Projeto acadêmico desenvolvido para consumir a API do TMDB de forma segura via servidor, listando a filmografia do ator Tom Hanks. A aplicação possui sistema de autenticação próprio e utiliza um banco de dados MariaDB para garantir que os favoritos e comentários de cada usuário fiquem totalmente isolados.
